# InstaGrab Chrome/Edge Extension

## Installation Instructions

1. Extract this `.zip` file into any folder (e.g., `Documents\InstaGrab-Extension`).
2. Open your browser:
   - **Google Chrome**: Go to `chrome://extensions`
   - **Microsoft Edge**: Go to `edge://extensions`
   - **Brave**: Go to `brave://extensions`
3. Toggle on **Developer mode** in the top right corner.
4. Click **Load unpacked** (in the top left corner).
5. Select the extracted `InstaGrab-Extension` folder.
6. Done! When you visit Pinterest (`pinterest.com`), you will now see a **Grab** download button on every pin!
